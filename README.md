# 💻 OOPs Lab — C++ Practicals

A collection of Object-Oriented Programming practicals written in **C++**, covering classes, constructors, destructors, inheritance, templates and file handling.

---

## 🚀 How to Run

```bash
# Compile
g++ "Practical-1.cpp" -o practical1

# Run
./practical1          # Linux / macOS
practical1.exe        # Windows
```

> Replace the file name with the practical you want to run. Use quotes for file names that contain spaces.
